# 采集调度策略管理工具

离线版采集调度策略配置工具，涵盖站点登记、模板编排、代理轮换、限速调节、反爬策略、增量水位与结果校验规则，所有配置持久化到浏览器本地存储。

这是一个**纯前端**管理平台：React + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

构建会先跑 `npm run verify:schema`：把 `frontend/src/data/validation.ts` 里的
`VALIDATION_SCHEMA_VERSION`（校验结果结构版本）当作依赖，核对种子数据里每条结果校验批次明细的
结构版本、必填字段与结论唯一性，任一失败即阻断构建；构建通过后的 `dist/` 即可部署到测试环境。

## 结果校验执行

结果校验模块在阈值配置之外提供校验执行能力（`frontend/src/api/validation-service.ts`）：

- **抽样校验**：读取待校验采集数据、规则的采样比例与异常阈值，等距抽样并归并异常证据，
  生成结果校验批次明细（批次编号、规则编号、最终结论、异常证据、确认历史、数据凭据、结构版本）。
- **原子提交**：采样结论、异常证据与落盘阻断在一次 localStorage 写入里一起提交，
  保存失败时整体不落库，不会出现已判通过但证据丢失。
- **结论唯一**：同一采集批次 + 同一规则重复校验是 upsert，批次明细永远只有一条记录、
  一个最终结论，上一份确认记录自动归档到确认历史。
- **冲突判定**：抽样异常率刚超阈值（超出部分 ≤5 个百分点）时挂起为「未决」，
  由复核员在「样本越阈值立即阻断」与「先扩展校验范围再作结论」之间判定，
  两种做法落盘状态不同，判定过程写入确认历史供复核。
- **失败重试**：校验失败（如采集数据行号缺失）可重试，重试先补发临时行号恢复数据，
  保留上一份确认记录与本日数据凭据，复核依据保持「样本越阈值立即阻断」。
- **落盘门禁**：数据落盘只接收批次明细中已通过的数据行；未决或阻断记录保留在隔离区
  等待复核（数据落盘页可查看落盘清单与隔离区）。完成落库后批次保留原采样状态。
- **角色**：校验员执行采样、重试与落盘回写；复核员判定冲突并核对
  「样本越阈值立即阻断」产生的核对记录。

校验执行域数据持久化在浏览器 `localStorage` 的 `scraper-strategy-studio:validation`
一项里，与模块清单数据互不影响。

## 业务模块

| 模块 | 目录 | 业务对象 | 主要字段 |
| --- | --- | --- | --- |
| 站点登记 | `site` | 采集站点 | 站点编号、域名地址、站点类型 |
| 模板编排 | `template` | 抽取模板 | 模板编号、入口地址、列表选择器 |
| 代理轮换 | `proxy` | 代理节点 | 节点编号、代理地址、代理协议 |
| 任务编排 | `spider` | 采集作业 | 作业编号、目标站点、抽取模板 |
| 调度编排 | `schedule` | 调度规则 | 规则编号、关联站点、调度表达式 |
| 反爬策略 | `antibot` | 对抗策略 | 策略编号、验证码类型、识别服务 |
| 限速调节 | `ratelimit` | 限速配置 | 配置编号、目标站点、每秒请求上限 |
| 重试机制 | `retry` | 重试策略 | 策略编号、关联任务、最大重试次数 |
| 字段映射 | `extractor` | 映射规则 | 规则编号、源字段名称、目标字段名称 |
| 采集流水线 | `pipeline` | 流水线步骤 | 步骤编号、步骤名称、输入数据源 |
| 结果校验 | `validator` | 校验规则 | 规则编号、校验对象、校验类型 |
| 数据落盘 | `storage` | 存储配置 | 配置编号、存储类型、输出路径 |
| 采集监控 | `monitor` | 监控指标 | 指标编号、关联任务、指标名称 |
| 数据清洗 | `cleanse` | 清洗规则 | 规则编号、目标字段、空值替换 |
| 增量水位 | `delta` | 增量游标 | 游标编号、目标站点、增量字段 |
| 数据分发 | `export` | 分发通道 | 通道编号、输出数据集、目标系统 |
| RPA流程 | `rpaflow` | 自动化流程 | 流程编号、目标页面、操作序列 |
| 登录凭证 | `auth` | 凭证配置 | 凭证编号、目标站点、认证方式 |

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `scraper-strategy-studio:entries` 这一项，或调用 `resetModule(模块)`。
